# 🇽🇰 Vizito Kosovën

Projekt i vogël në JavaScript të pastër (pa framework, pa server) për turizmin në Kosovë.

## Funksionet
- 12 destinacione (Prizren, Rugovë, Mirushë, Gadime, Brezovicë…)
- Kërkim dhe filtrim sipas kategorisë (Natyrë, Histori, Qytet, Aventurë)
- ❤️ Të preferuarat
- 🧳 Plan udhëtimi + shënime
- ⭐ Vlerësim për çdo destinacion
- 🌙 Temë e errët / e çelët

Të gjitha të dhënat e përdoruesit ruhen në **localStorage** – pa databazë.

## Si ta hapësh
Hape `index.html` në shfletues. Kaq.

## Struktura
```
index.html   – faqja
style.css    – stilet
data.js      – lista e destinacioneve
app.js       – logjika + localStorage
```
